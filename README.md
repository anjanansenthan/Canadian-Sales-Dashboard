Canadian Sales Dashboard

A beginner Power BI project analyzing sales data across Canadian regions and product categories — built while learning Power BI from scratch.

What it does

Explores sales trends, top regions, and product categories using a sample retail dataset. Includes KPI cards, a sales trend chart, and a region/category breakdown, all filterable by province.

Tools

Power BI Desktop, Power Query, DAX

What I learned / built
Cleaning and shaping data in Power Query
Building a data model with relationships (star schema)
Writing DAX measures like SUM, DISTINCTCOUNT, CALCULATE, and basic time intelligence
Creating an interactive, multi-page report with synced slicers
